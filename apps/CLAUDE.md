# ShiftCore Suite apps: Claude Code入口

このファイルは`apps/`配下をClaude Codeで扱う際の共通入口である。
固定ルールと現在の引き継ぎは、上で読み込む`AI_COLLABORATION_HANDOFF.md`にまとめている。

Claude Codeを`apps/`から起動すれば、このファイルを開始時に読み込める。リポジトリルートから起動した場合は、作業前に`apps/CLAUDE.md`を明示的に読ませ、`/memory`で読込対象を確認する。

## 作業開始時

1. 最新のユーザー指示を確認する。
2. リポジトリルート、現在ブランチ、`HEAD`、`git status`、関連差分を実データから確認する。
3. 対象に最も近い`CLAUDE.md`と`AGENTS.md`を読む。
4. 引き継ぎのスナップショットと実データが違う場合は、実データを優先して不一致を報告する。
5. 編集前に、担当機能、担当ファイル、触らない範囲を短く宣言する。

## プロジェクト別規則

- `shiftbuilder/`を扱う場合は、`shiftbuilder/CLAUDE.md`から専用の`AGENTS.md`を読み込む。
- 他のアプリでは、最新コードと各READMEを確認し、ShiftBuilder固有の仕様を流用しない。
- プロジェクト固有規則とこのファイルが衝突する場合は、対象に近い規則を優先する。ただし、ユーザーの最新の明示的指示、事実性、安全性が最優先である。

## Claudeへの重要事項

- CodexとClaudeが互いの会話を自動共有している前提にしない。
- 未コミット差分は、作成者が不明でも他者の作業として保護する。
- Claude自身が確認していないCodexの報告は「引き継ぎ情報」とし、Claudeの確認済み事実に変換しない。
- 機能実装の次目標は、えいちの依頼から確定する。直近コミットだけを根拠に勝手に続きを始めない。
